

\# RentTrack



RentTrack is a rental management application built as a full-stack portfolio project.



\## Technology Stack



\- Frontend: Angular and TypeScript

\- Backend: ASP.NET Core Web API with C#

\- ORM: Entity Framework Core

\- Database: Microsoft SQL Server

\- Testing: xUnit



\## Planned Features



\- Dashboard

\- Property management

\- Tenant management

\- Lease management

\- Rent payment tracking



\## Project Structure



\- `src/renttrack-ui` — Angular frontend

\- `src/RentTrack.Api` — ASP.NET Core API

\- `tests` — Automated tests

\- `docs` — Architecture and setup documentation

Development environment setup is in progress.
